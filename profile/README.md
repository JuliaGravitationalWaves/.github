# JuliaGravitationalWaves

Gravitational-wave data analysis in Julia.

| Package | Description |
|---|---|
| [GravitationalWaveData.jl](https://github.com/JuliaGravitationalWaves/GravitationalWaveData.jl) | Detector data toolkit: GWOSC and frame-file I/O, PSD estimation, filtering, whitening, Q-transforms and detector response |
| [GravitationalWaveforms.jl](https://github.com/JuliaGravitationalWaves/GravitationalWaveforms.jl) | Waveform models: IMRPhenomD/X family and SEOBNRv5HM/PHM, post-Newtonian inspirals; Float32/Float64-generic and differentiable, GPU-ready |
| [GravitationalWaveBayes.jl](https://github.com/JuliaGravitationalWaves/GravitationalWaveBayes.jl) | Parameter estimation: GPU-native batched likelihoods with Enzyme gradients, and NUTS, parallel-tempering and SMC samplers |
